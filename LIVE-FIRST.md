# FundBlick live-first development

Seit 2026-09-25 wird die sichtbare FundBlick-Oberfläche direkt auf `main` weiterentwickelt und über den Production-Pages-Workflow veröffentlicht.

Vor dem Wechsel wurde der vorherige Live-Stand auf `backup/live-before-live-first-2026-09-25` gesichert.

Interne Prüf-, Simulations- und Entwicklungsartefakte können weiterhin unter `development/` liegen. Sichtbare, freigegebene Änderungen werden jedoch direkt auf `main` umgesetzt und nach jedem relevanten Commit geprüft.
